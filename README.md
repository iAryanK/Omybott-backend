# Development Timeline

A chronological record of the project’s journey, from idea to release.

```text
●
│  Phase 01 — Entities creation
│  Created entities that gives an overall setup for entire app.
│  However, amendments can be made according to the circumstances.
│
●
│  Phase 02 — Authentication
│  Setup both JWT & google auth and created APIs for login, signup,
│  refresh etc.
│
●
│  Phase 03 — Workspace and Bot APIs
│  Created API endpoints related to workspace and bot setup.
│  
│
●
│  Phase 04 — Document and Document Chunk APIs
│  Created API endpoints to store metadata of document uploaded by user.
│  Also, the doc is converted into vector embedding and a chat endpoint
│  allows to interact with the knowledge base.
│
●
│  Phase 05 — Api key generation
│  Users can generate as many api keys for a bot.
│  The keys can be revoked as well.
│
▼
